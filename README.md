# Laboratoires de pentest Docker

Collection d’environnements locaux inspirés d’incidents réels, adaptés à l’entraînement. Chaque box utilisera une IP dédiée, un nom à associer dans `/etc/hosts` et les ports habituels de ses services. Legacy Telecom utilise `172.30.10.10`, `legacy-telecom.hns`, Nginx sur 80 et SSH sur 22.

| Box | Difficulté | État |
|---|---|---|
| [Legacy Telecom](legacy-telecom/README.md) | Très facile | Implémentée ; voir le compte rendu des vérifications |
| Dispute Center | Facile | Prévue |
| Forgotten Logger | Moyenne | Prévue |
| Contractor Access | Difficile | Prévue |
| Poisoned Pipeline | Très difficile | Prévue |

Commencer par le [guide de lancement de Legacy Telecom](legacy-telecom/README.md).
